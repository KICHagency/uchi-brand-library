# ILLUSTRATION_QA — автоматическая самопроверка с исправлением

**Версия 3.0.** Применять к **готовому изображению**, а не к описанию. Каждый критический FAIL запускает новый цикл исправления; максимум 3 цикла. Если критерий нельзя проверить, указать `UNVERIFIED`.

## Критические гейты
- **G01 Объектность:** только физические предметы. Никаких детей, учителей, людей, рук, ног, человеческих лиц или гуманоидных фигур.
- **G02 Узнаваемость:** один главный объект читается без подписи, соответствует смыслу ТЗ.
- **G03 Палитра:** только разрешённые цвета режима аудитории; у учителей нет кислотного подросткового зелёного. Точную проверку токенов отмечать подтверждённой только при доступных значениях.
- **G04 Конструкция:** намеренное, но осмысленное искажение и skew; условная боковая толщина, без полноценной 3D-перспективы/пластикового рендера.
- **G05 Акценты:** 1–3 смысловых акцента; нет случайного фона, шумовых деталей и ненужных точек.
- **G06 Края:** прозрачность, когда запрошена; отсутствие белой каймы, следов маски, дефектов обтравки.
- **G07 Миниатюра:** ключевой силуэт читается после уменьшения; микродетали не превращаются в шум.
- **G08 Сходство:** силуэт, толщина, углы и композиционный язык сверены с подлинными эталонами, если те доступны. Если недоступны — `UNVERIFIED`, не PASS.

## Вторичные гейты
Оптическая уравновешенность; целостность фактуры; 80/20 узнаваемость и деформация (художественный ориентир, не метрический критерий); выборочная округлость; отсутствие избыточных элементов; правильные поля.

## Протокол
1. Сгенерировать изображение.
2. Проверить G01–G08 по видимому результату, а не по JSON или описанию.
3. Если FAIL — записать ID ошибки и точно сформулировать корректировку (например, «G05: убрать две жёлтые точки и фоновую фигуру»).
4. Заново сгенерировать/отредактировать и перепроверить. Не писать «исправлено», если исправленная картинка не получена.
5. По истечении 3 циклов выдать лучший результат, но с честным FAIL или UNVERIFIED при нерешённой проблеме.

## Итоговый отчёт
`Объект | Аудитория | Попытки | PASS-критерии | FAIL-критерии | UNVERIFIED-критерии | Статус`. Утверждение дизайнером отдельно от автоматического QA.

## QA v3 — обязательная матрица без самообмана
| ID | Вопрос по реально сгенерированному изображению | Причина FAIL / коррекция |
|---|---|---|
| G01 | Есть только физический объект? | Человек/часть тела → убрать и перегенерировать |
| G02 | Силуэт узнаётся; не похож на резину? | Полностью волнистое тело → вернуться к простой форме |
| G03 | Видно именно shear, а не один поворот? | Только повернули объект → перерисовать с косыми гранями |
| G04 | Толщина — логичная боковая плоскость, без 3D каждой детали? | Экструзия всех клавиш → сделать детали плоскими |
| G05 | Углы намеренно разные, не все одинаково мягкие? | Все одинаковые капсулы → вернуть острые элементы |
| G06 | Цветовые массы принадлежат режиму аудитории? | Лишние градиенты/тонировки → только утверждённые заливки |
| G07 | Нет декоративных сторонних лучей/лент/«гребешков»? | Каждая необоснованная внешняя фигура → удалить |
| G08 | Читается при уменьшении? | Слишком много мелочей → сократить |
| G09 | Чистая кромка и настоящая прозрачность? | Белые/чёрные артефакты, фальшивый фон → FAIL |
| G10 | Сопоставлены 2–3 библиотечных утверждённых объекта? | Сравнения нет → UNVERIFIED, а не PASS |

Для каждого критерия давать наблюдаемое свидетельство (например, «слева внешняя жёлтая петля») вместо бездоказательного `PASS`. При отсутствии доступа к пикселям/альфе для G06/G09 отмечать `UNVERIFIED`. Не считать близость к последней клавиатуре доказательством стиля — это пока только **лучший экспериментальный результат**.

**Результат теста предыдущей итерации v3:** G01 PASS, G02 скорее PASS, G03 и G04 требуют проверки геометрии; G07 FAIL (коралловые лучи и жёлтая ленточная петля); G06 и G09 объективно не подтверждены. Следовательно, картинка **не была fully PASS**.

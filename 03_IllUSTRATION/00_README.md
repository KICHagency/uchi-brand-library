# UCHI ILLUSTRATION SYSTEM — AI AUTO-GENERATION v3.0

Цель: получать фирменные **предметные** иллюстрации Учи.ру непосредственно через генератор изображений, со встроенной проверкой и корректирующими повторами. **Ручная перерисовка не является обязательным шагом пайплайна.**

## Главные файлы
- `illustration_style.json` — **основной машинный промпт** с ограничениями, порядком построения и циклом самопроверки.
- `01_ИНСТРУКЦИЯ_ILLUSTRATIONS.md` — рабочий протокол AI.
- `02_ILLUSTRATION_STYLE.md` — правила, извлечённые из Figma-гайда.
- `03_OBJECT_LIBRARY.md` — категории утверждённых предметных ассетов.
- `04_AUDIENCE_AND_COLOR.md` — цвет и характер разных аудиторий.
- `05_ILLUSTRATION_QA.md` — тестирование по изображению, исправления, статусы.
- `06_BRIEF_TEMPLATE.md` — входящее ТЗ.
- `07_LINKS.md` — ссылки на первоисточники.
- `08_SOURCE_AUDIT.md` — происхождение правил и ограничения.

## Структурное правило
**Только физические объекты, не люди.** Не генерировать ребёнка, школьника, учителя или гуманоидного персонажа. Для образовательного сообщения подобрать предметную метафору.

## Совместимость
Подключать общие `BRAND_CORE.md`, `COLOR_SYSTEM.md`, `GRAPHIC_SYSTEM.md` из 00_CORE. По цветам `COLOR_SYSTEM.md` имеет приоритет. Если рендерящий генератор не умеет читать JSON напрямую, передать ему поля `generation_prompt`, `hard_constraints`, `construction`, `audiences` и `negative_prompt_concepts` как обычный промпт.

## Честная проверка
Проверка модели по картинке улучшает качество, но не гарантирует пиксельное соответствие референсам. Не маркировать непроверенные свойства как PASS.

## Изменения v3 — зафиксированные итерации клавиатуры
- Первые попытки отклонены: слишком резиновая деформация, объёмные 3D-клавиши, случайные лучи и фоновая светло-фиолетовая «корона».
- Последняя итерация **ближе к нужной геометрии**, но **не утверждена как эталон**: коралловые лучи и жёлтая ленточная петля также не имеют подтверждённой функции.
- **Новое правило по умолчанию: никаких внешних акцентов вообще**. Добавлять их можно только при явной смысловой необходимости и опоре на утверждённый источник.
- Skew необходимо проверять **по искажению геометрии**, а не по тому, что изображение наклонено.
- Проверка выполняется **после** генерации по 10 гейтам из `05_ILLUSTRATION_QA.md` и JSON.
- Папка `QA_CASES/` содержит изображения итераций только как историю теста, а не фирменные эталоны.

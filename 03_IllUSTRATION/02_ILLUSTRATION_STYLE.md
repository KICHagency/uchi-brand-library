# ILLUSTRATION_STYLE — технические правила графики
Основание: страница Guide → `ILLUSTRATIONS GUIDE`, 17 разделов, и страница `Library` в Figma. Версия 1.0.

## Главная формула
**Обычный предмет → узнаваемый простой силуэт → намеренное искажение → скос → дополнительная плоскость → 1–3 акцента.** У иллюстрации должен быть контролируемый хаос и характер, но она должна оставаться легко считываемой.

## Предметность и запреты
В этом проекте **исключены изображения людей и детей**. Темы обучения и эмоции передаются через материальные объекты. Гайд разрешает характер/оживление предметных форм для 0–4 и подростков; это не разрешение на отдельные человеческие/детские персонажи. Антропоморфные детали (глазки, элементы Гриши) использовать только когда это оправдано задачей и аудиторией; не добавлять по умолчанию.

## Геометрия
| Характеристика | Значение из гайда |
|---|---|
| Artboard | 240×240 px |
| Safe Area | 192×192 px |
| Visual Core | 128×128 px |
| Основная / дополнительная сетки | 8 / 4 px |
| Основной приём | Skew / Shear |
| Дополнительный приём | Rotate |
| Основное направление | вправо, левый наклон допускается с направлением динамики вправо |
| Угол крупного объекта / акцента / супер-акцента | 10° / 20° / 30° |
| Ориентир характера | 80% узнаваемости / 20% странности |
| Радиусы | 2 px мелкие, 4 px средние, 6 px крупные, full для полностью скруглённого |

Начинать с фронтального объекта; не перегружать деталями. Можно ломать симметрию/пропорции и намеренно выйти из идеальной сетки после искажения. Не скруглять все углы; для мягкой конструкции — более острый акцент, для острой — мягкий. Не делать случайных геометрических ошибок.

## Объём
- Только условная пластика, **не 3D и не реалистичная перспектива**.
- Базовый объект = фронтальная плоскость + боковая «толщина»; перспективу допускается намеренно ломать.
- Третья плоскость — только когда улучшает форму/читаемость.
- Плоские в реальности объекты (бумага, лента, текст) не уводить в объём.
- Самая тёмная плоскость не обязательно теневая; композиционный контраст важнее физической достоверности.

## Акценты
Один смысловой объект + 1–3 эмоциональных акцента. Акценты и вспышки — вторичные цвета; деталь должна помогать композиции. **Нельзя:** 4+ акцента, куча мелочи, случайные жёлтые точки/гребешки/подложки, не объясняемые смыслом, если они не требуются в утверждённом примере.

## Масштабирование
При уменьшении до иконки удалять мелкие детали и шум, можно увеличить крупные акценты. Система построения остаётся: ориентир 80% смысл / 20% акцент. Иконка, иллюстрация и баннер — не один PNG в трёх размерах; им нужны разные уровни детализации и композиция.

## Характер по сегментам
- **0–4:** крупные мягкие формы, яркая палитра; иногда живость и глазки/элементы Гриши (не автоматически).
- **5–11:** более острые, дерзкие формы; динамика, контраст, возможно кислотные акценты только из своей палитры.
- **Учителя:** спокойная универсальная форма, без кислотности и яркого контраста; монохром / пастель, без добавления случайной живости.

## Запрещено
Реалистичные предметные рендеры, полноценное 3D, фотореалистичные тени, все углы скруглённые, цвета вне палитры, случайная кривизна, чрезмерно подробная картинка, человек/ребёнок/ученик/учитель как фигура, визуально шумный фон, незапрошенные предметы.

## AI vs чистовая иконка
В гайде прямо сказано: AI допустим как помощь при поиске идеи/композиции/формы; итог нужно вручную привести к системе. Для чистового построения рекомендуется Illustrator, Figma — библиотека, документация и проверка. Не использовать маски в чистовой конструкции.

## Дополнение v3 — реальные ошибки генератора и ограничения
**Недостаточно** попросить «playful, tilted, soft 3D». Такая лексика неоднократно приводила к гладкой изометрической иконке, а не к фирменному рисунку.

- **Искажение:** работаем с углами и отдельными пропорциями, а не со сплошным волнообразным изгибом корпуса. Узнаваемая форма должна доминировать.
- **Skew:** главный приём — направленный *shear* формы; `rotate` самостоятельной заменой не является. Важно видеть сдвиг верхней части относительно нижней и характерные наклонные линии, не только наклон изображения. Значения из гайда 10° / 20° / 30° — ориентиры для композиции, а не гарантия измерения на PNG.
- **Объём:** одно связное тело и одна боковая плоскость толщины; не превращать каждую деталь в 3D-экструзию. Плоскость должна иметь понятное место соединения с основной поверхностью.
- **Скругления:** не делать все углы одинаково скруглёнными. Держать ритм острых и мягких переходов; скругление после искажения.
- **Декор:** под запретом по умолчанию лучи, «гребешки», вспышки, ленточные петли, подложки и независимые фигуры вне объекта. Даже если они в пределах 1–3 акцентов, они НЕ проходят QA без связи со смыслом и подтверждения в гайде.
- **Цвет:** точный поднабор разрешённых токенов; при недостаточности доступа к пикселям не обещать совпадение HEX. Отсутствие людей обязательно.

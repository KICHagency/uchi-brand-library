## Технические значения
240/192/128 px; сетка 8/4; skew/shear 10°/20°/30°; скругления 2/4/6/full; узнаваемость/странность 80/20; 1 смысловой объект + 1–3 акцента; условный объём из 2 плоскостей; без полноценного 3D; Illustrator рекомендован для чистовой иконки, Figma для библиотек/проверки; без масок.

## Важный нюанс
Гайд допускает «делать персонажей»/добавлять объектам живость для 0–4 и подростков. Пользователь дополнительно установил **более строгое ограничение: никаких людей/детей — только материальные объекты**. Поэтому данный пакет разрешает исключительно предметные иллюстрации; оживление предметов допустимо лишь при явном запросе, а человеческие персонажи запрещены.

## Ограничения проверки
- Структура и тексты всех нормативных разделов прочитаны, но сотни библиотечных векторных объектов **не проверены один за другим визуально**.
- Точный реестр цветовых HEX не дублирован: см. общий COLOR_SYSTEM.md.
- JSON — формализация описанных правил, **не гарантия** точного style transfer для любого изображения.
- Не установлены требования к лицензированию/публикации ассетов и пиксельные параметры рендера, которых нет в гайде.

## Обратная связь по генерациям, ноябрь 2026
**Источники:** письменные замечания заказчика к трём тестовым клавиатурам. Замечания — факты обратной связи, не текст брендбука.
- v1: небрендовые цвета, слишком сильное искажение.
- v2: небрендовые лучи и светло-фиолетовый «гребешок», нет видимого skew, слишком аккуратный/неинтуитивный объём.
- v3: ближе к правильному характеру, но результат не объявлен утверждённым. Устранение внешних эффектов и корректная деформация остаются задачей.

**Изменения правил:** запрещены по умолчанию любые произвольные внешние акценты, в том числе при соблюдении формального лимита 1–3; отдельно оцениваются shear vs rotate, характер боковой плоскости, локальное искажение vs «резина», реальные цветовые заливки и артефакты по краю.

**Ограничение:** самопроверка — требуемый процесс, а не автономная функция JSON или гарантия исполнения генератором. Для полной автоматизации должен существовать оркестратор, который действительно запускает проверку выходного изображения и повторную генерацию.

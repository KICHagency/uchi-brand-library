# OBJECT_LIBRARY — правила библиотеки предметных иллюстраций
Версия 1.0. Источник: Figma `Illustrations-guide---library`, страница `Library`.

## Категории, явно названные в библиотеке
- Иконки и вспомогательные элементы: лупа (`lupa`), часы (`clock`), будильник (`alarm`), математические символы (`transportir`, `neravno`, `koren`, `parabola`, `grafic`, `progress`).
- Курсы и предметы: программирование, финансовая грамотность, шахматы, физика, литература, история, английский, окружающий мир, обществознание, математика, русский язык.
- Категории предметов: `учёба`, `еда`, `хобби`, `техника`, `природа`, `вещи`.
- Отдельные рубрики: `иконки`, `предметы`, `Гриша`, `жесты`, `Курсы и игры`.

Это **индекс обнаруженных категорий и названий**, не гарантия, что каждый объект оформлен как опубликованный Figma Component. Часть объектов — обычные фреймы/векторы; повторное использование проверяется в исходном файле.

## Процедура поиска
1. Найти готовый объект по названию, визуальному сходству или семантическому семейству.
2. Если есть готовый, предпочесть reuse / изменение цветового варианта, не изобретать его снова.
3. Если требуется новый объект, выбрать ближайшие 2–3 утверждённых предмета как **стилевые референсы** по форме/объёму/акцентам, но не копировать чужой предмет.
4. При адаптации к другой аудитории менять разрешённую палитру и характер, не «перекрашивать всё одним цветом».
5. Не использовать раздел `Гриша` как разрешение рисовать нового человека/ребёнка. Применять только существующие фирменные элементы в допустимом контексте.

## Материальные метафоры
Идея «учиться» → учебник/тетрадь/карандаш/линейка; «время» → часы/таймер; «поиск» → лупа; «успех» → предметный кубок/награда. Эти примеры — **допустимая логика выбора предмета**, не утверждённые конкретные готовые иллюстрации.

## Техническое правило
При ссылке на библиотечный ассет сохранять его точное имя, node ID и аудиторию; если компонент не опубликован, не выдавать за опубликованный. Ссылки — в `07_LINKS.md`.

## v3 — правило сравнения с библиотекой
Сравнение должно проводиться по **2–3 реальным утверждённым физическим объектам** той же степени сложности. Не считать три тестовые клавиатуры эталонами фирменного стиля. При сравнении фиксировать: долю главного силуэта, реальный характер сдвига граней, количество и направление плоскостей объёма, переходы острых и мягких углов, количество внутренних деталей. Если реальные примеры недоступны, пометить style-match `UNVERIFIED`.

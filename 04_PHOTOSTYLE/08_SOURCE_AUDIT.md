# Аудит источников — Uchi Photo

Проверены страницы `Guide` (15 слайдов), `Процесс` (слайды 16–22 и дополнительные фото), `Артефакты`, `архив` и `Обложка`. На странице Guide извлечены текстовые правила всех 15 слайдов и проверены образцы композиций.

## Что точно подтверждено
- Редакционный lifestyle-фотостиль, реальные люди и естественная образовательная ситуация.
- Светлая обжитая среда, натуральный дневной свет, нейтральная обработка.
- Для родителей, учителей, детей 0–7 и подростков — разные сюжеты/эмоции/цветовая выразительность.
- Особый вариант широкоугольной фотоистории родителей (около 14 мм, верхняя камера), не универсальный режим.
- Для фото с обтравкой — студийный свет, видимые лица, натуральная мимика, аккуратные края.
- Запрещены «очевидный AI», пластиковая кожа, CGI, фильтры, выдуманные надписи, сурреализм, жёсткие тени и стоковая постановка.
- На «Процессе» существует отдельный Uchi.ru Teacher Brand Photography JSON v3.0, из которого взята подходящая структура input / cameras / realism / QA.

## Исключено
- Процесс, слайды **16–20**, принадлежат **Media Platform**, а не Учи.ру. Не переносить их зелёный свет и графитовые фоны.
- Архивные варианты не автоматически утверждены.

## Что требует осторожности
- Цвета `#FF909B` и `#7CBBF0`, встречающиеся на слайде 22, не являются подтверждёнными названиями примитивов в ранее прочитанном `COLOR_SYSTEM.md`. Поэтому составлена безопасная палитра на основе подтверждённых базовых цветов.
- Цифровой генератор не может гарантировать идентичную внешность человека при отсутствии референса; при работе с реальными людьми отдельный приоритет — узнаваемость, без изменения внешности.
- Страница «Артефакты» содержит набор изображений, но не текстовую классификацию PASS/FAIL; интерпретация каждого изображения требует отдельного просмотра.
- Все изображения исходников автоматически не выгружены в архив: ссылки на страницы сохранены; Figma остаётся первоисточником.
- Новый JSON собран как универсализация teacher JSON v3.0 и правил остальных сегментов; это не утверждённый официальный JSON и ещё не прошёл тестовую генерацию.

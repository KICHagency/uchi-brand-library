# UCHI.RU — PHOTO GENERATION

Версия: 1.1. Материалы проверены по Figma `https://www.figma.com/design/3eWn7eGdgGOot2wWbhndZf/G-%7C-%D0%A4%D0%BE%D1%82%D0%BE%D1%81%D1%82%D0%B8%D0%BB%D1%8C`.

## Цель
Генерировать фотоматериалы Учи.ру без обязательного участия ретушёра в каждом цикле, с самопроверкой результата и явной фиксацией ошибок. Результат генерации **не автоматически утверждён** дизайн-командой.

## Состав
- `01_ИНСТРУКЦИЯ_PHOTO.md`: сценарий AI + Figma + ТЗ.
- `02_PHOTO_STYLE.md`: правила эстетики и камер.
- `03_AUDIENCE_SCENARIOS.md`: сегменты аудитории.
- `04_COMPOSITION_AND_ASSETS.md`: композиция, кроп, обтравка, логотипы.
- `05_PHOTO_QA.md`: самопроверка и итерации.
- `06_BRIEF_TEMPLATE.md`: бриф сотрудника.
- `07_LINKS.md`: Figma-источники.
- `08_SOURCE_AUDIT.md`: аудит, исключения, неопределённости.
- `photo_style.json`: машинная спецификация.

## Подключение к CORE
Использовать вместе с `BRAND_CORE.md`, `COLOR_SYSTEM.md` и главным `ИНСТРУКЦИЯ.md`.

## Приоритет
1. Утверждённый фотогайд Учи.ру, страница `Guide`.
2. Актуальная цветовая система/токены Учи.ру.
3. `photo_style.json` и специализированные инструкции.
4. Утверждённые реальные изображения и макеты при наличии.
5. ТЗ — для переменных сюжета и композиции, но не для отмены брендовых норм.

Важное исключение: **страница «Процесс», слайды 16–20 — Media Platform; не использовать.** Слайд 22 — Uchi.ru Teacher Brand Photography v3.0, использовать с проверкой конфликтов.

## Что изменилось в комплекте v1.1
- `07_LINKS.md` расширен ссылками на конкретные изображения и все сегменты фотогайда.
- `09_PROCESS_REFERENCES.md` — отдельный реестр фото со страницы «Процесс».
- Оригинальные фотографии из Figma в ZIP не включены: без отдельного экспорта нельзя считать их скачанными. Ссылки Figma остаются точками доступа.
- Для генераций используйте `photo_style.json`, а не JSON Media Platform со слайдов 16–20.

Этот документ закрепляет **конкретные фотографии**, на которые следует ориентироваться при генерации, чтобы не копировать случайные фотографии другого проекта.

Ссылки — в `07_LINKS.md`.

## Применение

1. Сначала определить аудиторию, сюжет и тип кадра.
2. Использовать соответствующие правила в `photo_style.json`.
3. Визуально сверять свет, естественность поз, интерьер и цвет с подходящим снимком из списка, если Figma доступна.
4. Не копировать личность реального человека или её индивидуальные особенности из референса без явной задачи.
5. Не брать материалы Media Platform со слайдов 16–20.
6. Фиксировать недостаточную проверку по референсу как `UNVERIFIED`, а не `PASS`.

**Важно:** файлы изображений не встроены в этот пакет. Для автономного режима экспортировать утверждённые фото из Figma в подпапку `REFERENCES/`, если имеется право на их использование. Рекомендуемое имя основного референса: `teacher_classroom_laptop_reference.png`.

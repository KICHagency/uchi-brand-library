# ТЗ на генерацию фотографии

Скопируй и заполни. Можно оставить неизвестные поля пустыми.

- **Целевая аудитория:** родители / учителя / дети 0–7 / подростки.
- **Задача / носитель:** письмо / SMM / баннер / лендинг / презентация.
- **Сюжет / действие:**
- **Герои:** кто, возраст, одежда, особенности внешности (без необходимости указывать этничность).
- **Предметы:** ноутбук / телефон / книга / учебные материалы и т. д.
- **Среда:** дом / класс / школа / парк и т. д.
- **Эмоции:**
- **Камера:** на уровне глаз / сверху / широкоугольная / обтравка.
- **Формат:** соотношение сторон и размер.
- **Кадрирование:** поясной / общий / крупный план.
- **Свободное место под текст:** слева / справа / сверху / не требуется.
- **Ограничения:**
- **Figma, куда вставить:** (необязательно).

## Стартовый запрос
> Изучи `photo_style.json` и PHOTO-гайды. Сгенерируй реалистичную фотографию по ТЗ. Соблюдай сегмент, камеру, свет, цвет и сохранность лиц/рук/предметов. После генерации проверь изображение по `05_PHOTO_QA.md`. Исправь блокирующие ошибки и дай честный отчёт PASS/FAIL/UNVERIFIED. Не применяй стилистику Media Platform.

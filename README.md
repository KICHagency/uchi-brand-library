## Запрос для нового чата

> Открой https://github.com/KICHagency/uchi-brand-library и начни с README. Прочитай общую инструкцию и файлы по моей задаче. Назови файлы, которые удалось открыть, и используй их в работе.  
> **Задача** — [что собрать или сгенерировать]. **Аудитория** — [сегмент]. **Формат и размеры** — [канал, размеры, версии]. **Текст** — [заголовок, подпись, CTA]. **Figma** — [ссылка на файл и нужный фрейм].  
> Используй правила выбранного сегмента и профильный JSON, если он есть. Проверь результат по чек-листу. Если у тебя есть доступ на редактирование в Figma, собери или обнови указанный фрейм и дай ссылку на результат. Если редактирование недоступно, выдай готовые ассеты и параметры для ручной сборки. Укажи, что не удалось проверить.

## Доступ

Репозиторий публичный. Инструкции, JSON-промпты и ассеты на GitHub доступны без входа в аккаунт. Вставьте ссылку в ИИ-инструмент, который умеет открывать веб-страницы. Если он не может прочитать нужный файл по ссылке, скачайте файл и приложите его к запросу. Для открытия закрытых референсов и редактирования макета нужны соответствующие права в Figma.

Фотографии со страницы «Процесс» доступны по ссылкам на Figma в разделе фотостиля. PNG в папке QA иллюстраций показывают ошибки и промежуточные итерации.

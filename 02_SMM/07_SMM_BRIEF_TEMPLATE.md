# Шаблон ТЗ — SMM / Chatbot / Ads

Скопировать в запрос сотрудника; неизвестные поля можно оставить пустыми, если они не критичны.

```yaml
задача: ""
аудитория: "родители | учителя | другое"
тип: "одиночный пост | карусель | Stories | реклама | чат-бот | PDF-памятка"
цель: ""
площадка: ""
форматы: ["1080x1080"]
число_карточек: "4-6 по умолчанию для карусели; точное количество при наличии"
основной_тезис: ""
контент_по_карточкам: []
исходный_текст: ""
факты_без_изменений: []
cta: ""
ссылки: []
обязательные_лого: []
фото_или_иллюстрации: "нужны / не нужны / предоставить"
референс_в_figma: ""
рабочая_figma: ""
дополнительные_ограничения: ""
```

Если предоставлен только длинный текст, AI сначала предлагает его распределение по кадрам; сокращение/перефразирование важных формулировок не считается автоматически согласованным.

# SMM_FIGMA_ORGANIZATION — структура источников и правила работы

## Источники
1. `G | SMM гайд` — актуальные шаблоны, компоненты, сетки, паттерны, анимационные варианты.
2. `SMM-Teachers` — рабочие материалы учительского сегмента: спецификации/шаблоны, месячные доски (сентябрь–ноябрь 2026), `Чат-бот`, `System`, Archive.
3. `SMM-Parents` — рабочие материалы родительского сегмента: спецификации, месячные доски (сентябрь–ноябрь 2026), `иллюстрации`, `чат-бот`, `System`, Archive.

## Приоритет
`00_CORE` + актуальный `G | SMM гайд` → утверждённые компоненты → подходящие реальные примеры из сегментного файла → ТЗ. Референс не делает случайное решение общей нормой.

## Организация работы
- Чётко определить сегмент **до** выбора рабочего файла.
- Не перезаписывать утверждённые макеты, архив, библиотеку компонентов.
- Для новых работ создать отдельный рабочий файл или согласованную рабочую страницу; назвать фреймы по теме, типу, порядковому номеру и формату.
- Если серия карусельная: держать все кадры одной серии рядом и в определённом порядке; не смешивать альтернативные концепции с утверждёнными версиями.
- Не делать вывод, что вся страница `System` — инструкция SMM: в обоих файлах обнаружены общие/унаследованные материалы, а в учительском файле есть блок `mail-system` с CRM-правилами `Status`/`Liner`. Для SMM эти правила не подтверждены как обязательные.
- Страницы `Archive`, `OLD`, `Creative`, `Примеры` могут содержать исторические либо экспериментальные материалы; они полезны для изучения, но не становятся нормативными без подтверждения.

## Работа с макетами для чат-ботов
Материалы лежат в отдельных страницах и включают квадратные посты, вертикальные изображения и листы A4. Не переносить автоматически форматы обычного SMM. См. `05_SMM_CHATBOT.md`.
